# Better Clicky

Companheiro de voz para o macOS: segure **Control + Option**, fale, e o Better Clicky responde em voz alta, aponta na tela e executa tarefas no seu Mac.

## Baixar

**[Baixar a versão mais recente](https://github.com/alenkpedro/better-clicky-releases/releases/latest)** — macOS 14.2 ou mais novo.

1. Abra o `.dmg` e arraste o **Better Clicky** para **Aplicativos**.
2. Na primeira abertura, clique com o botão direito no app → **Abrir** (o app não é autenticado pela Apple).
3. Depois disso, as atualizações chegam sozinhas pelo próprio app.
